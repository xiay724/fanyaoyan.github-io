# 豫见真相 · 反谣同行（河南辟谣公益宣传 H5）

一个围绕 **三农、经济、教育、医疗、文化旅游** 领域的反谣言公益宣传 H5 单页作品，融合 **河南本地文化**，支持电脑 / 手机 / 平板自动适配。

## 快速使用

- **直接打开**：双击 `index.html` 即可在浏览器中浏览（无任何外部依赖，可离线运行）。
- **在线部署**：把 `index.html` 上传到任意静态服务器（如 Nginx、GitHub Pages、OSS）即可分享。

## 四大交互形式

| 形式 | 位置 | 说明 |
| --- | --- | --- |
| 传统滑动式 | 全篇 | 由上向下逐屏滑动呈现介绍 |
| 路线式 | 第 3 屏「豫地辟谣路线」 | 以河南地图为底，沿安阳→焦作→洛阳→郑州→南阳→信阳 6 站展示各地辟谣案例 |
| 卡片反转式 | 第 4 屏「卡片反转」 | 点击（电脑端悬停）卡片即翻转，揭晓权威真相 |
| 互动式 | 第 5、6 屏 | 「击碎谣言」点击互动 + 「拼出真相」3×3 滑动拼图 |

## 页面结构（共 8 屏）

1. 封面 · 豫见真相
2. 为何反谣（权威数据）
3. 豫地辟谣路线（地图）
4. 卡片反转 · 真相揭晓
5. 击碎谣言（互动游戏）
6. 拼出真相（滑动拼图）
7. 防谣五招 · 河南版
8. 结尾 · 反谣承诺书（可生成、复制、分享）

## 设备自适应

- 启动时通过 **UA + 屏幕宽度 + 触摸能力（pointer: coarse）** 综合识别设备并自动切换交互方式，全程静默适配、不额外展示标识。
- **手机**：上下滑动手势翻页 + 顶部进度条 + 横屏时弹出「竖屏体验更佳」提示。
- **平板**：滑动 / 点按翻页，布局加宽、触控点放大。
- **电脑**：滚轮 / 方向键 / 空格翻页 + 右侧圆点导航 + 悬停卡片翻转。
- 布局另用 CSS 媒体查询（1024 / 820 / 480px）保证内容在窄屏不截断、可滚动。

## 技术说明

- 纯原生 HTML + CSS + JavaScript，单文件、零依赖、无网络请求。
